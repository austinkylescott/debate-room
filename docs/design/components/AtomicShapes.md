# AtomicShapes

The Atomic shape vocabulary: fifteen mid-century shapes, each with one job in the product.

| Shape | Job |
|---|---|
| Amoeba | Holds the Prompt |
| Kidney | Holds the Floor |
| Boomerang | Movement, toasts |
| Leaf with spine | The Disagree and Agree poles |
| Compass star | Your notch; the reveal |
| Ball starburst | A notch; lock-in confirmed |
| Sparkle | Small celebrations |
| Surfboard | Countdowns |
| Teardrop pendant | Notices hanging from the top bar |
| Atom | The orbit language; timers |
| Crosshair | Alignment hairlines |
| Bowl | Middle Ground's middle |
| Diamond | Raised hands |
| Arrow | Up next |
| Ring and dot | Surrounded's Center and chair |

Paths are drawn in a 100×100 box centred on 0,0, so they can be scaled and rotated freely. Fill colours come from the `*` fill tokens; spines, balls and hairlines use `ink`. Shapes never sit behind running text.
