# Tag

Small pill labels for Pack tone (Chill ● / Spicy ▲), roles (Host, Co-Host, Participant, Spectator) and Room status.

- **Classes:** `.dr-tag`, plus `--chill`, `--spicy`, `--host`, `--cohost`, `--spectator` or `--live`.
- **Rules:** Chill and Spicy differ by shape as well as colour, and the word is always written out. Long text truncates on one line.
- **Not interactive.** Use a button for filters.
